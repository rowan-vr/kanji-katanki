# Changelog

## 0.1.0 — Initial public beta

- Generate independent kanji recognition, writing, and Parts cards from vocabulary.
- Preview card creation and refresh managed examples while preserving progress.
- Include offline dictionaries, vocabulary suggestions, and stroke diagrams.
- Track kanji learning with target lists, statistics, and review history.
- Convert supported existing cards with backup, scheduling preservation, and Undo.
- Guide first use with restartable, collection-local setup.

Verified baseline: Linux, Anki 26.09.3 / Python 3.14.8. Other platforms and older
Anki versions remain unverified. See `docs/ANKIWEB_RELEASE.md` for upload steps.
